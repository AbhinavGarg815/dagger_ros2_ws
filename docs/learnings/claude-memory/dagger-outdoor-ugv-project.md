**Dagger** is an autonomous **caterpillar/tracked diff-drive rover**, ~350 kg, **outdoor-use only** (user confirmed 2026-07-08).

Compute/stack: Jetson Orin Nano 8GB, JetPack 6 / L4T R36.5, ROS 2 Humble. Control chain: Jetson → **MAVROS** → **Cube Orange Plus running ArduPilot Rover** → track motors. Jetson commands velocity in GUIDED mode via `/mavros/setpoint_velocity/cmd_vel_unstamped`. IMU + GPS come from the Cube via MAVROS.

Sensors: Robosense Helios-16P LiDAR (`/rslidar_points`), Intel RealSense D435, u-blox NEO ("pro 3", non-RTK) GPS/GNSS. Workspace: `/home/jetson/ros2_ws` (accessed via SSH; not a git repo). User packages: `dagger_controller`, `dagger_description`, `dagger_slam`, `msgs_comm`. Vendored: kiss-icp, realsense-ros, rslidar_sdk/msg.

Target capabilities: waypoint nav, obstacle avoidance, SLAM, follow Google-Maps route on road, follow-me (person/object/car).
