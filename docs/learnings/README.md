# Learnings

`claude-memory/` is a copy of the project memory Claude Code keeps while working on Dagger:
what was decided and why, lessons that cost time, hand-offs between sessions, and the
standing rules for working on the rover. `MEMORY.md` is its index.

It is refreshed by `bash tools/sync_learnings.sh` (run at every session wrap-up) — edit the
originals, not this copy. Detailed evidence for every lesson (measurements, bags, commits)
is in [`../reports/issues_and_fixes.md`](../reports/issues_and_fixes.md); its sections
"H. Diagnostic pitfalls" collect the debugging mistakes worth not repeating.
